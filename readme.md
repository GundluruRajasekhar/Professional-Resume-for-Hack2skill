# Rajasekhar G. — Resume: Program Manager, Hackathons

A single-file HTML resume positioned for hackathon/event program management
roles (built with the Hack2skill Program Manager – Hackathons posting as the
reference brief).

## Files
- `index.html` — the resume itself. Open directly in any browser.
- `requirements.md` — scope, role signal, and constraints behind the build.
- `Tasks.md` — build checklist, including items still left for you to fill in.
- `readme.md` — this file.

## How to use it
1. **Fill in the remaining placeholders** before sending it anywhere:
   - LinkedIn URL
   - University name and graduation year
2. **Open `index.html`** in a browser to preview.
3. **Export to PDF**: browser print dialog (Ctrl/Cmd + P) → Save as PDF.
   A print stylesheet is already included so margins and page breaks come
   out clean on A4/Letter.
4. **Tailor per application**: the project grid at the bottom can be swapped
   to whichever 2–3 apps are most relevant to a given posting — you don't
   need to show all 20+ every time.
